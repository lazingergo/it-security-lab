# it-security-lab

This repository contains my solutions and working files for the IT Security lab series.

## What is in the repository

- `lab1/` - Input validation and CIFF image handling, including a Python GUI viewer and a C++ parser extension.
- `lab2-security-testing/` - Software security testing exercises based on the earlier input validation lab.
- `lab3-memory-corruption/` - Stack-based memory corruption exercises and exploit development.
- `lab4-client-and-server-side-web-security/` - Web security exercises focused on XSS, SQL injection, and Juice Shop challenges.
- `lab5-crypto/` - Cryptography exercises using PyCryptodome, including AES-CBC, hybrid encryption, RSA-OAEP, and RSA-PSS.

## Short overview

The labs cover common security topics from low-level memory bugs to web attacks and cryptography. Each folder contains the provided assignment material, supporting files, and in several cases my completed solutions or notes.
